# コミュ記録（拡張機能・自分用）

シャニマスのコミュを読みながら、画面に出た**台詞・タイトル・選択肢**を読み取って、
ダウンロードフォルダの `コミュログ/タイトル_日時.txt` に保存する Chrome / Vivaldi 拡張機能。
光空記録総覧の「スクショで探す」の本文集めに使う。

- ゲームの操作は一切しない。0.6秒ごとに画面を撮って、台詞の枠などの文字を読むだけ。
- 進め方は自由（自分でクリック・ゲームのオート）。早送りは撮影が追いつかないので不可。
- 文字の読み取りは同梱の Tesseract.js（Apache-2.0）。画像はどこにも送らない。

## 入れ方
1. `./build.sh`（`scripts/ocr` で `npm install` 済みであること）で `lib/` をそろえる
2. Vivaldi の 拡張機能 → デベロッパーモード → 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ

## 使い方
シャニマスのタブで拡張のボタン →「記録を始める」（または Ctrl+Shift+9）。
台詞が30秒増えないか、次のコミュのタイトルが出たら保存する。止めたときも保存する。

## ファイル
| ファイル | 役割 |
|---|---|
| manifest.json | 拡張の設定 |
| background.js | 記録の繰り返し・保存（画面を撮って offscreen に渡す） |
| offscreen.js | ゲーム画面を見つけ、台詞の枠・タイトルの帯・選択肢を切り出して読む |
| popup.html / popup.js | 拡張のボタンを押したときの画面 |
| build.sh | Tesseract.js を lib/ に同梱する |
